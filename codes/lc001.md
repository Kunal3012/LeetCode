# Intuition
The most optimal way to solve this problem is to find the complement (`target - num`) **on the fly**. Instead of scanning the array multiple times, we can track visited numbers in a dictionary. By checking for the complement *before* adding the current number to the dictionary, we find the answer in a single pass and naturally avoid using the same index twice.

# Approach
1. **Single-Pass Hash Map:** Initialize an empty dictionary `d` to map values to their indices.
2. **Native Iteration:** Use `enumerate(nums)` to fetch both the index `i` and the value `num` efficiently.
3. **Direct Membership Check:** Calculate the required complement `r = target - num`. Use `if r in d` to query the hash table directly instead of calling `.keys()`, removing method overhead.
4. **Instant Match:** If `r` is found, immediately return `[d[r], i]`. Otherwise, save the current number `d[num] = i` and keep moving.

# Complexity
- Time complexity:
\[O(n)\]
*The list is traversed exactly once. Each dictionary lookup and insertion runs in average O(1) time.*

- Space complexity:
\[O(n)\]
*In the worst case, the dictionary stores up to n elements.*

# Code
```python3 []
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        d = {}
        for i, num in enumerate(nums):
            r = target - num
            if r in d:
                return [d[r], i]
            d[num] = i
```
